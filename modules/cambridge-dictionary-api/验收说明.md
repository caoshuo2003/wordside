# 模块验证

本模块基于 Nongfsq 解析器，测试使用合成页面、原始解析器对照与临时 loopback HTTP 服务，不依赖 Cambridge 公共网络。

```sh
npm test
```

覆盖成功 JSON 字段/顺序、中文/例句归属、页面完整性、错误类别、缓存、并发合并、超时与 Cambridge 候选。原始代码对照仅在测试中执行；详见 [UPSTREAM.md](UPSTREAM.md)。

在线检查可用 `npm run probe`，但网络时延与真实词库结果可能随时变化，不把它作为 CI 必需测试，也不把本模块测试视为桌面取词或安装验收。应用首版证据见 [WordSide 发布说明](../../docs/releases/v0.1.0.md)。

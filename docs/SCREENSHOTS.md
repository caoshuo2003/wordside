## 怎么重新录动图

1. 阅读页是自写的本地 HTML，正文下面放一组彩色插图，好让卡片的毛玻璃透出颜色。用单独的 Edge 配置目录（放在 `.cache` 下）以 `--app` 窗口打开；页面加载后自己按字逐个选中单词，并把单词位置写进标题，不向浏览器发送任何输入。
2. 先启动卡片：`wordside.exe --payload apps/wordside/dev/sample-run.json --light --stay`，把窗口隐藏并移到单词下方；页面选完单词后再以不激活的方式显示，选区保持蓝色，和真实查词一样。
3. 录屏进程要 DPI 感知，只按物理像素截取页面内容区，每 40 ms 一帧，画出真实鼠标指针。鼠标只在卡片上移动，依次停在三条释义上，看到浮起的玻璃高亮。
4. 用 ffmpeg 缩到 880 宽，结尾 0.5 秒淡回第一帧，全片一张调色板加误差扩散抖动编成 GIF（约 1.4 MB）。录屏脚本和 ffmpeg 都放在 `.cache`，不进仓库。

静态截图的做法相同：只截阅读页和卡片两者。更新界面后同步图片；使用示例词条和自写文字，不含私人信息。涉及真实桌面录屏时，先征得当前操作者同意，并确认画面里没有其他窗口。

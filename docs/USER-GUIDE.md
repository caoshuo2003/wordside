# WordSide · 词伴使用指南

选中英文，查看释义，然后继续阅读。

## 运行与第一次查词

WordSide 0.3.1 支持 **Windows x64**，需要可访问 Cambridge 的网络，不需要 WebView2。

| 方式 | 操作 |
|---|---|
| 安装版 · 推荐 | 下载 `WordSide_0.3.1_x64-setup.exe`，按提示安装。只装给当前用户，不需要管理员权限；完成页可以选“现在运行”和“开机时自动启动” |
| 单个程序 | 下载 `WordSide_0.3.1.exe`，放到任意文件夹，双击运行 |
| 便携包 | 下载 `WordSide_0.3.1-portable.zip`，解压后运行其中的程序；包内附使用说明和第三方许可 |

程序没有数字签名，Windows 可能提示“已保护你的电脑”，点“更多信息”→“仍要运行”。

运行后不会弹出窗口，WordSide 在任务栏右下角的托盘待命（可能收在 ^ 里）。左键点托盘图标，卡片打开，在顶部输入英文单词或短语，按 Enter 即可查看词条。

再次双击程序不会多开，只会打开已经在运行的那一个。

### 从 0.2.0 升级

1. 在托盘右键旧版图标，选择“退出 WordSide”。
2. 运行新版安装包：它会自动卸载已安装的 0.2.0，再装上新版。用的是 0.2.0 便携版的，直接删除旧文件夹。
3. 自动划词开关、查词快捷键和浅色/深色设置会沿用；0.2.0 的配色和浮窗大小不再使用。

## 选择查词方式

| 方式 | 怎么用 |
|---|---|
| 自动划词 | 托盘右键勾选“自动划词”，在其他应用里双击或拖选英文单词，卡片出现在选区旁边 |
| 快捷键 | 选中单词后按 **Ctrl+Alt+A**；关闭自动划词后也可以使用。没选中任何东西时按，会打开空白卡片供输入 |
| 手动输入 | 左键点托盘图标，或在卡片的查词框输入英文单词，按 Enter |

卡片出现时不会抢走原窗口的焦点，可以接着打字。点卡片以外的地方，卡片自动收起。

要修改快捷键：点卡片右上角的齿轮（或按 Ctrl+,）打开设置，选中“查词快捷键”按 Enter，再按下新的组合；Esc 取消，Backspace 停用快捷键。快捷键被其他程序占用时，托盘会给出提示，点提示可以直接去修改。

有些应用或文本区域读不到选区，这时可以在卡片里手动输入。尽量选取单词本身，避免带上整条命令、文件路径或整段文字：自动划词遇到这类选区不会弹出卡片，按快捷键时会提示重新选词。

## 阅读释义与播放发音

卡片顶部是单词和音标，点击音标旁的喇叭可以听英式或美式发音。单词较长时，音标统一放到下一行；音标多到一行放不下时，可以左右拖动或用滚轮查看。卡片上第一次播放会稍等约半秒，这是在等耳机或声卡唤醒，免得单词开头被吞掉；之后连续点、来回切换读音都会立刻从头播放。下面的词性标签显示各词性的释义条数，点击或按 Tab 切换；Cambridge 没有标词性的释义归在“其他”。词性多到一行放不下时，标签行边缘会渐隐，左右拖动或在上面滚动滚轮就能看到其余的；按 Tab 切换时会自动滚到选中的那个。

每条释义中文在前、英文在后。有例句的释义右侧会显示“例句 N”，点一下展开，再点一下收起。内容较长时在卡片里滚动阅读。

键盘操作：↑↓ 选择释义，→ 展开例句，← 收起，Tab 切换词性，Ctrl+P 播放下一个发音，Esc 收起卡片。

部分词条只有英文解释，会标记“仅英文”；英汉词库没有该词时，WordSide 会尝试英英词库。如果词典给出的词条与查询词不同，会显示“查询词 → 词条”。想看词典原页，点底部的“原词典”。

在释义上右键，可以复制单词、复制这条释义，或在 Cambridge 打开。

## 移动与固定卡片

| 操作 | 效果 |
|---|---|
| 拖动卡片 | 移动到别处 |
| 点击右上角的图钉 | 固定卡片：点别处不再收起，后续查词在同一张卡片更新 |
| 再点一次图钉，或按 Esc | 取消固定 / 收起卡片 |

卡片宽度固定，高度随内容变化，最高约 420 像素，再长就在卡片里滚动。拖动后的位置暂时不会记住，下一次查词卡片会重新出现在选区旁边。

## 选词不完整或没查到

划词时多选到的旁边字符会自动去掉：

- 首尾的符号，例如 `“runtime,”`、`<terminal>=`、`--workspace`、`record™`。
- 紧挨着的中文，例如 `使用runtime的`。
- 脚注标记，例如 `record[1]`、`record¹`。
- 越过句号、逗号多选到的下一句开头一两个字母，例如 `Dictionary. T`、`e. Dictionary`。两边都是完整单词时（`word. The`）不会自己挑一个，请重新选词。

单词内部的撇号和连字符会保留，例如 `don't`、`run-time`。

划词时如果词典查不到，WordSide 会再试两种写法：去掉首尾的数字（`record2` → `record`），或去掉两头一两个字母的残片（`e record`、`record a` → `record`）。查到后，输入框会显示实际查询的单词。手动输入的单词按原样查询。

还是查不到时，若词典提供拼写建议，卡片会显示候选，点击其中一个继续查询，也可以回到输入框修改单词。路径、网址、命令和日志不会被拆出单词，按快捷键时会提示重新选词。

连接失败时，可以稍后再查一次；具体排查办法见[网络与速度](FAQ.md#网络与速度)。

## 外观

在设置的“外观”里选择 **跟随系统 / 浅色 / 深色**。卡片默认是半透明的拟态玻璃；如果在 Windows 设置里关闭了“透明效果”，卡片会自动换成不透明的样式。

## 托盘与退出

托盘右键菜单：

- **查词**：打开卡片输入单词，旁边显示当前的快捷键。
- **自动划词**：打勾表示开启。
- **设置**：在卡片里打开设置。
- **退出**：结束 WordSide。

## 网络、本地设置与删除

查词直接访问 Cambridge Dictionary，播放发音时从该网站获取音频。需要代理时可使用 Windows 系统代理，配置方法见[网络与速度](FAQ.md#网络与速度)。

自动划词开关、快捷键和外观保存在本机的设置目录；复制程序到另一台电脑时，设置需要重新配置。位置和内容见[隐私与本地数据](PRIVACY.md)。

安装版在 Windows“设置 → 应用 → 已安装的应用”里卸载，开机自动启动也会一并去掉；单个程序和便携包从托盘退出后删除文件即可。卸载不会删除个人设置，想一并清除请参考[重置设置](PRIVACY.md#重置设置)。

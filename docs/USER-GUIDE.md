# WordSide 使用指南

> 选中英文 → 自动查词或按快捷键 → 在阅读旁查看释义。

[下载 0.1.0](https://github.com/caoshuo2003/wordside/releases/tag/v0.1.0) · [常见问题](FAQ.md) · [返回首页](../README.md)

## 1 · 安装与第一次运行

需要 **Windows x64**、**Microsoft Edge WebView2** 和可访问 Cambridge 的网络。无需安装 Node、Rust 或额外 API 服务。

| 方式 | 操作 |
|---|---|
| 安装版 | 下载 `WordSide_0.1.0_x64-setup.exe`，按安装器提示完成，打开 WordSide |
| 便携版 | 下载 `WordSide_0.1.0-portable.zip`，解压全部文件，再运行同目录的 exe |
| 独立 exe | 运行 `WordSide_0.1.0.exe`；同一 Release 提供第三方许可 |

若已有 WordSide 正在运行，先在托盘右键退出，再打开新版；否则新程序可能交给旧实例处理。打开后设置底部应显示 **0.1.0**。

![WordSide 设置](images/settings-light.png)

*示例设置截图，使用当前界面；新安装默认快捷键 Ctrl+Alt+A，可以修改并保存。*

## 2 · 选择查询方式

**自动划词**：打开开关，在其他应用选中单词。WordSide 成功读到选区后显示释义。关闭开关可以避免阅读时频繁弹出。

**快捷键查词**：选中单词后按 **Ctrl+Alt+A**。你可在设置中重新录入并保存快捷键；自动划词关闭时，快捷键仍可使用。升级会保留已保存的快捷键。

**手动输入**：在 WordSide 输入英文单词或短语，点击查询。遇到无法读取选区的应用，可直接使用此入口。

自动和快捷键取词依赖应用的选区接口，不保证所有软件或文本区域可用。不要将整个命令、文件路径或跨行内容当作单词提交。

## 3 · 阅读词条

![日间释义示例](images/popup-light.png)

词条展示英文解释、已有中文翻译、例句、词性及发音。点击播放按钮听英式或美式发音；“展开全部例句”可打开收起的例句。长词条在窗口内部滚动，不会删除内容。

- 英汉词库明确没有该词时，再尝试英英。
- 缺中文仍保留英文，用“英文释义”或“部分仅英文”标记。
- 词典返回不同拼写时显示“查询词 → 词条”，帮助确认实际查到的词。
- “原词典”可在浏览器打开对应词条。

读取与校验网页后一次显示结果；网络速度由你访问 Cambridge 的连接情况决定。

## 4 · 移动、调整与固定

| 操作 | 效果 |
|---|---|
| 拖动顶部 CAMBRIDGE 及旁边空白 | 移动释义浮窗 |
| 拖动四边或四角 | 调整宽高；最小 320×360，初始 360×600 |
| 点击“固定” | 保持窗口可见；后续自动/快捷键查词在同一窗口更新，保留位置和大小 |
| 关闭释义浮窗 | 只收起释义，不退出程序 |

固定后也能移动、缩放。窗口尺寸会自动记住并在重启后保留；固定状态不跨重启保存。解除固定或收起后，下一次弹窗重新跟随取词位置。当前屏幕容不下窗口时会临时适配。

窄窗口发音分成单列，拉宽后可排成两列。设置窗口默认 440×540，最小 400×520。

## 5 · 少选、多选或没有中文

`“runtime,”`、`<terminal>=` 一类边缘符号会自动清理。词内撇号、连字符保留，如 `don't`、`run-time`。

多选或少选字母时，WordSide 不会擅自补齐。两种词库都没有结果，且 Cambridge 提供候选时，界面显示“你可能想查”，点击候选后查询；也可以直接更正输入。片段本身是有效词时（如 `term`），会正常返回该片段，不猜测你原本想查的长词。

![拼写建议示例](images/suggestions.png)

未找到词条、连接失败、查询较慢和内容不可用有各自的简短提示。网络失败可以重试；缺词可以更正输入或点击建议。没有中文的词条仍能阅读英文解释。

## 6 · 主题与配色

在外观中选择 **薄荷绿 / 雾紫 / 浅蓝 / 暖灰**，再选择 **日间 / 夜间 / 跟随系统**。设置自动保存。

![夜间释义示例](images/popup-dark.png)

## 7 · 托盘与退出

设置中的“关闭主窗口时”提供两种行为：

- **隐藏到托盘**：关闭设置后仍可划词；双击托盘图标直接重新打开。
- **退出 WordSide**：关闭主窗口即结束程序。

托盘右键菜单可切换自动划词、打开 WordSide 或退出。左键不弹出菜单。关闭释义窗口始终只收起当前释义。

## 8 · 网络、设置和卸载

WordSide 支持 Windows 系统代理和 `HTTPS_PROXY / HTTP_PROXY / NO_PROXY` 环境变量，不会修改你的系统代理。配置办法见 [网络 FAQ](FAQ.md#网络与速度)。

窗口尺寸、快捷键和外观保存在本机设置中；词条仅在内存缓存，退出清空。便携版指程序可解压运行，设置仍保存在系统应用配置目录，随身携带 exe 不会自动带走设置。

便携版退出后删除解压目录即可；安装版从 Windows“已安装的应用”卸载 WordSide。卸载后若仍需删除偏好，可参考 [隐私与本地数据](PRIVACY.md)。

所有截图为隔离预览，使用示例内容，不是跨应用兼容或安装验收的证明。

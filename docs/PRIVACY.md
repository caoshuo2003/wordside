# 隐私与本地数据

WordSide 为选中的英文查词，不提供帐号、云端词条同步或 AI 翻译。

| 数据 | 处理方式 |
|---|---|
| 查询词 | 发往 Cambridge 查询词条；使用代理时流量同时经过你选择的代理 |
| 释义和候选 | 有限内存缓存：15 分钟，最多 32 条 / 12 MiB；退出清空，不保存到磁盘 |
| 自动开关、快捷键、主题、配色、窗口尺寸 | 保存到本机应用配置目录 |
| 选区兼容记录 | 有限临时记录，用于本次选择取词；不形成磁盘历史词库 |
| 发音 | 播放时从 Cambridge 获取音频 |
| “原词典” | 在默认浏览器打开词条，适用该浏览器和网站自身的设置 |

直接选区读取不模拟复制。原应用的“选中即复制”可能自行更新剪贴板；兼容路径可能读取这一更新，不能替代关闭源应用自动复制的设置。

Windows 配置位于 `%APPDATA%\local.wordside.dictionary.api-preview\settings.json`。标识保留用于兼容已有偏好，与产品显示名称 WordSide 无关。先退出程序再删除该文件，可重置设置；不要提交此文件或真实选词记录到源码库。

诊断命令可能输出查询词与返回结果，仅在你需要排查时使用。报告问题前移除敏感文本、帐号、代理凭据和私人截图。

Cambridge 的数据处理由其网站政策决定；WordSide 与其无官方关联。

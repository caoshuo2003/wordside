# 隐私与本地数据

下面说明 WordSide · 词伴查词时会访问哪些服务，以及哪些数据会保留在本机。

[使用指南](USER-GUIDE.md) · [常见问题](FAQ.md) · [返回首页](../README.md)

## 查词时的数据

| 数据 | 处理方式 |
|---|---|
| 查询词 | 发往 Cambridge 获取词条和拼写建议；使用代理时，流量也会经过你选择的代理 |
| 已查到的词条 | 短期缓存在内存，缓存有效期为 15 分钟，退出程序后清空 |
| 拼写建议 | 查询时获取，显示为本次查询的候选 |
| 发音 | 点击播放时从 Cambridge 获取音频 |
| 点击“原词典” | 在默认浏览器打开词条，遵循该浏览器与网站自身的数据设置 |
| 自动开关、快捷键、主题、配色、窗口大小 | 保存在本机应用配置目录，供下次打开使用 |
| 选区兼容记录 | 临时保留本次选词记录，用于取词；与词条缓存一样，只保存在内存 |
| 最近一次取词故障 | 设置目录中的 `capture-status.json` 仅保存版本、时间、故障阶段与状态代码，最多 4 KiB；新故障覆盖旧记录，不含单词、应用身份或剪贴板内容 |

## 选区与剪贴板

WordSide 会通过源应用的标准复制功能核对实际选词，自动划词和快捷键使用同一方式。复制前先在内存中备份当前剪贴板，读取后尝试恢复；期间你新复制的内容会优先保留。

只有已枚举的实际内容都能独立保存时才开始校对。常见文本、位图、文件列表和可保存的富文本按格式保留；遇到无法保留的应用专用内容、虚拟对象或超过 64 MiB 的数据时，会保持当前内容并提示手动输入。备份在本次操作结束后释放，不写入文件。

临时复制仍可能被 Windows 剪贴板历史、同步或第三方剪贴板工具记录。源应用很迟才响应复制、请求被取消或 Windows 拒绝恢复时，也可能留下临时内容；备份恢复不能撤销这些外部影响。读取超时会停止本次查词，不会继续使用旧剪贴板查询。

部分应用开启“选中即复制”后，会在选中时自行更新剪贴板。WordSide 可能读取本次更新作为取词的兼容方式；这项自动复制可以在原应用中关闭。

## 重置设置

Windows 设置文件位于：

```text
%APPDATA%\local.wordside.dictionary.api-preview\settings.json
```

先从托盘退出 WordSide，再删除该文件。重新打开后会恢复默认设置。目录名称沿用早期版本，以便继续使用已有偏好。

安装版和便携版都在这个位置保存设置。卸载或删除程序后，如果想同时清除个人偏好，也可以按上面的步骤处理。

## 反馈问题时

取词失败可提供 `capture-status.json`，它只记录最近一次故障的状态。发送截图或其他开发日志前，请移除敏感文本、账号信息与代理凭据；网络调试输出可能包含查询词和返回结果，按需提供即可。

词典网站自身的数据处理由其政策决定，内容来源与许可说明见[NOTICE](../NOTICE.md)。

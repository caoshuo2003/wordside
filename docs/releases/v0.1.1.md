# WordSide · 词伴 0.1.1

**选词更宽容，查词更顺手。**

这次更新集中改善 PDF 取词和快捷键体验。选区多带上一个短横线，也可以继续查词。

[下载文件](https://github.com/caoshuo2003/wordside/releases/tag/v0.1.1) · [使用指南](https://github.com/caoshuo2003/wordside/blob/main/docs/USER-GUIDE.md) · [常见问题](https://github.com/caoshuo2003/wordside/blob/main/docs/FAQ.md)

## 本次改进

- **更准确地读取 PDF 选词。** 核对源应用实际复制的文字，改善读到相邻内容、选区发生偏移的问题。
- **快捷键更可靠。** 改善偶发无响应、需要重复按键，以及自动划词与快捷键互相干扰的情况。关闭自动划词后，仍可按快捷键查询。
- **少操心一点标点。** `-workspace`、`--workspace` 会查询 `workspace`；`don't`、`state-of-the-art` 中的撇号与连字符继续保留。
- **更妥善地处理取词失败。** 改善剪贴板备份和超时恢复；读不到时，可以重新选词或直接输入。

## 下载与开始

| 文件 | 怎么选 |
|---|---|
| `WordSide_0.1.1_x64-setup.exe` | 推荐安装版，按提示安装 |
| `WordSide_0.1.1-portable.zip` | 解压全部文件后运行 |
| `WordSide_0.1.1.exe` | 单独运行主程序 |
| `THIRD-PARTY-LICENSES_0.1.1.txt` | 本版第三方许可说明 |

需要 **Windows x64**、Microsoft Edge WebView2 和可访问 Cambridge 的网络。

升级前，先在右下角托盘右键退出旧版 WordSide，再打开新版。原有快捷键、配色和窗口大小会继续保留；首次使用的默认快捷键为 **Ctrl+Alt+A**。

## 使用与验证情况

本版已在 Windows 桌面实测普通文本区和 **Zotero 10.0.6 的测试 PDF**：自动选词、关闭自动后的单次快捷键、首尾短横线处理、空选区提示和失败后重新取词。也核验了原剪贴板中的测试文本、图片和文件列表，以及固定浮窗在同一位置更新新词。

取词效果仍取决于具体应用和文本区域，不能保证每个 PDF 都能读取。查词会临时复制选区并尝试恢复原剪贴板，具体处理和边界见[隐私与数据](https://github.com/caoshuo2003/wordside/blob/main/docs/PRIVACY.md#选区与剪贴板)。本轮重点验证取词；安装、升级、卸载和跨屏 DPI 的完整实测仍待补充。

如果突然无法使用，可以先在托盘退出，再重新打开；反馈时请说明应用、软件版本与操作步骤。[问题反馈](https://github.com/caoshuo2003/wordside/issues)

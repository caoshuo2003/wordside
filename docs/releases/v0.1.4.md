# WordSide · 词伴 0.1.4

- 修复刚启动时取词无反应的问题；取词窗口初始化失败后会自动重试。
- 修复长时间闲置或开机时系统繁忙后，取词失灵、需要退出重开才能恢复的问题；现在会自动恢复。
- 修复在 Chrome 网页（如 GitHub）中按快捷键取词时，误提示“请重新选词”的问题。
- 改善 Pebrel 终端中的自动划词与快捷键取词。
- 复制取词时不再抢先占用剪贴板，减少偶发的“这里暂时无法取词”。
- 查词浮窗在 Windows 11 上使用系统圆角与细边框，颜色跟随配色。
- 主窗口标题栏跟随配色；查词框移到顶部，自动划词改为开关，设置分组整理。

更新前，请先从托盘退出旧版，再安装或运行新版；原有设置会保留。

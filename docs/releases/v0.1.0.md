# WordSide 0.1.0 · 首次发布

当前完整桌面实现作为 GitHub 的第一版代码基线，目标为 **Windows x64**。这是 0.x 版本，不承诺所有应用均能读取选区。

## 功能

- 自动划词、独立快捷键、手动输入；关闭自动后仍可主动查词。
- Cambridge 英汉 / 英英、完整核心释义和例句、音标与发音。
- 边缘符号清理、确认缺词后的拼写建议；候选需手动点击。
- 浮窗拖动、自由缩放、尺寸记忆；固定后同一窗口更新，保留位置与大小。
- 四套日夜配色，简洁用户提示；缺中文保留英文内容。
- 主窗口关闭方式可选托盘或退出，双击托盘直接打开，右键显示菜单。
- Rust 内置查询、复用连接、有限内存缓存、取消和旧请求隔离；发布包无需 Node 或 API 服务。

## 下载与运行

| 文件 | 说明 |
|---|---|
| `WordSide_0.1.0_x64-setup.exe` | Windows x64 安装包 |
| `WordSide_0.1.0-portable.zip` | 解压全部文件后运行，含程序、许可与说明 |
| `WordSide_0.1.0.exe` | 单独运行主程序 |
| `THIRD-PARTY-LICENSES_0.1.0.txt` | 同版第三方许可 |

需要 Windows x64、WebView2 与可访问 Cambridge 的网络。先从托盘退出旧版，再打开本版；设置底部显示 **0.1.0**。便携版仍在系统应用配置目录保存偏好。

EXE **13,737,984 字节（13.10 MiB）**；安装包 **3,203,546 字节（3.06 MiB）**。程序不含 Node 运行时、独立查询服务或磁盘词条缓存。

## 检查与限制

本版沿用已验证的当前功能代码，仅重编号并整理首次发布资料。已有 **51 项 JS/共享/提示、43 项 Windows 原生逻辑、52 项隔离 UI + 1 项浏览器超时** 检查覆盖功能行为；首版从独立源码目录完成锁文件安装、51 项 JS 测试与类型/UI 构建、43 项原生逻辑及另 2 项纯快捷键解析检查；重新构建并核对 Windows 成品版本、离线解析与分发许可。GitHub 的实际 CI 状态见 [Actions](https://github.com/caoshuo2003/wordside/actions)。

隔离 UI 使用独立 headless Edge、示例数据与模拟 Tauri；文档截图来自该界面，不是在线或跨应用桌面验收。原生 HTTP 测试使用临时本机服务，覆盖连接复用、超时/取消、错误分类与代理；不能据此承诺公网延迟。

**真实桌面取词/快捷键、托盘双击/退出、DPI 跨屏，以及安装/升级/卸载仍未在本轮验收。** 网页响应与结构属于外部依赖；短语跳转可能返回不同头词，查看“查询词 → 词条”确认。Linux / CLI / tmux、词形与 AI 功能不在本版范围。

# WordSide · 词伴 0.1.0 · 首次发布

**Windows x64 · 正式首版**

在支持读取选区的 Windows 应用中，选中英文单词，或按快捷键，在小浮窗里查看 Cambridge Dictionary 的释义与发音。

[下载文件](https://github.com/caoshuo2003/wordside/releases/tag/v0.1.0) · [使用指南](https://github.com/caoshuo2003/wordside/blob/main/docs/USER-GUIDE.md) · [常见问题](https://github.com/caoshuo2003/wordside/blob/main/docs/FAQ.md) · [隐私与数据](https://github.com/caoshuo2003/wordside/blob/main/docs/PRIVACY.md)

## 这一版可以做什么

- 自动划词、快捷键和手动输入；关闭自动后仍可按快捷键查词。
- 查看英汉或英文释义、例句、音标，播放英式与美式发音。
- 清理首尾符号，没查到时查看词典提供的拼写建议。
- 拖动与缩放浮窗，记住大小；固定后在同一窗口继续查新词。
- 四套配色，搭配日间、夜间或跟随系统模式。
- 关闭主窗口时选择隐藏到托盘或退出，双击托盘重新打开。

## 下载与使用

| 文件 | 怎么选 |
|---|---|
| `WordSide_0.1.0_x64-setup.exe` | 推荐安装版，按提示安装后使用 |
| `WordSide_0.1.0-portable.zip` | 解压全部文件，运行其中的 WordSide |
| `WordSide_0.1.0.exe` | 单独运行主程序 |
| `THIRD-PARTY-LICENSES_0.1.0.txt` | 本版第三方许可说明 |

需要 Windows x64、Microsoft Edge WebView2 和可访问 Cambridge 的网络。安装包约 **3.06 MiB**，独立程序约 **13.10 MiB**。打开 WordSide 后可以直接手动查词，或在设置中开启自动划词；默认快捷键为 **Ctrl+Alt+A**。

若旧版仍在运行，先在托盘右键退出，再打开本版。便携版的设置也会保存在 Windows 应用配置目录，详见隐私说明。

# WordSide · 词伴 0.1.2

**选词和快捷键，更顺手一些。**

这次更新重点改善“明明选中了，却提示无法取词”、需要重复按快捷键，以及双击或拖选偶尔不触发的情况。

[下载 WordSide](https://github.com/caoshuo2003/wordside/releases/tag/v0.1.2) · [使用指南](https://github.com/caoshuo2003/wordside/blob/main/docs/USER-GUIDE.md) · [常见问题](https://github.com/caoshuo2003/wordside/blob/main/docs/FAQ.md)

## 本次改进

- **快捷键取词更可靠。** 修正 Alt+D 因松键顺序干扰原应用的问题，选好单词后可以一次触发；连续查词时使用当前选区。
- **自动与手动各自顺手。** 开启自动划词时，双击或拖选可以直接查询；关闭后，仍可按自己的查词快捷键。
- **改善记事本与输入框的取词。** 常见系统文本控件直接读取准确选区，减少临时复制。关闭上一个浮窗后，也能继续选词。
- **短暂失败可以恢复。** 读取遇到暂时异常时，在原选区内受限重试一次；继续保留密码输入和剪贴板保护。
- **更妥善地保护剪贴板。** 改善复杂格式和延迟提供内容时的备份与恢复。

| 文件 | 怎么选 |
|---|---|
| [Windows x64 安装包](https://github.com/caoshuo2003/wordside/releases/download/v0.1.2/WordSide_0.1.2_x64-setup.exe) | 推荐安装版，按提示安装 |

需要 **Windows x64**、Microsoft Edge WebView2 和可访问 Cambridge 的网络。

更新前，先在右下角托盘右键退出旧版 WordSide，再打开新版。原有快捷键、配色和窗口大小会继续保留；首次使用的默认快捷键为 **Ctrl+Alt+A**，可以在设置中修改。

## 使用与验证情况

本次修复已在 Windows 桌面完成以下检查，用户试用后也确认效果改善。

| 使用场景 | 验证范围 |
|---|---|
| Windows 系统记事本 | 拖选、双击、自动开关及单次 Alt+D，核对实际选区和源控件焦点 |
| Edge 网页与输入框 | 网页正文、单行、多行和可编辑区域；不同按键释放顺序，核对选区与焦点保持 |
| Zotero 10.0.6 测试 PDF | 自动与手动取词、双击、拖选，以及 `-workspace`、`--workspace` 的处理 |

这些场景共 **29 项实机检查通过**，相关 Windows 原生回归 **185 项通过**。实机检查使用发布前的修复候选；正式 0.1.2 从同一修复代码重新构建并检查发行包。不同应用和 PDF 的选区接口仍可能存在差异；安装、升级、卸载及跨屏 DPI 的完整实测未在本轮进行。

常见系统文本控件直接读取选区；需要进一步核对时，可能临时复制并尝试恢复剪贴板。具体处理见[隐私与数据](https://github.com/caoshuo2003/wordside/blob/main/docs/PRIVACY.md#选区与剪贴板)。

遇到问题时，可以先在托盘退出 WordSide，再重新打开。若问题仍然存在或能够复现，欢迎[提交 Issue](https://github.com/caoshuo2003/wordside/issues)，附上 WordSide 版本、相关应用和操作步骤。

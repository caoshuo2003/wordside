# WordSide · 词伴 0.3.1

更小、发音更完整、选词更省心。

- **更小**：程序约 1.8 MB（0.3.0 约 4.2 MB），安装包约 0.8 MB。联网改用 Windows 自带的加密连接和证书，查词结果和以前完全一样。
- **发音完整**：单词开头不再被吞掉（`dictionary` 只听到 `tionary`），快速来回切换英式、美式读音也一样，而且立即播放。
- **选词更省心**：多选到的符号、紧挨着的中文、脚注编号（`record[1]`）、越过句号多选到的下一句开头（`Dictionary. T`）都会自动去掉；查不到时再试去掉首尾的数字或旁边单词的一两个字母。路径、网址和命令仍然不会被拆出单词。
- **放得下了**：词性多的词（如 `in`）的标签和较长的音标行可以左右拖动或用滚轮滑动，边缘渐隐提示还有更多；单词太长时，音标整行放到下一行。
- **更清楚**：1080p 屏幕（100%、125% 缩放）上中文不再高低不平；释义里网页带来的换行显示成一个空格，不再出现 `form of` 下面隔几行才是 `be`。

## 更新

- 用安装版的：先在托盘右键退出 WordSide，再运行 0.3.1 的安装包，会直接替换旧版。0.2.0 的安装版也会被自动卸载。
- 用单个 exe 或便携包的：退出后用新文件替换旧文件。
- 设置（自动划词、快捷键、外观）都会沿用。

## 已知限制

- 卡片宽度固定，拖动后的位置暂不记住；多显示器、不同缩放比例下的位置还在完善。
- 开着自动划词时，程序会定时检查选区，CPU 偶尔有极少占用；关闭自动划词时为 0。
- 卡片内容暂不支持屏幕阅读器。
- 程序没有数字签名，Windows 可能提示“已保护你的电脑”，点“更多信息”→“仍要运行”。
- 有的网络访问 Cambridge 会被要求人机验证，这时无法查词，可以换一个网络再试。

# WordSide · 词伴 0.1.3

- 修复 GitHub 等网页连续自动划词或快捷键取词时，偶发提示“请重新选词”的问题。
- 修复 PowerShell 7 终端使用 Alt+D 等快捷键时，选区被清除而无法取词的问题。
- 修复 `minutes` 等独立短语词条无法显示释义的问题。
- 修复自动取词期间按键干扰导致同一次取词重复启动的问题。

更新前，请先从托盘退出旧版，再安装或运行新版；原有设置会保留。

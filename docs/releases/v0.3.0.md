# WordSide · 词伴 0.3.0

重写的新一代。整个程序改用 Rust 原生实现，界面换成一张拟态玻璃卡片：选中单词，卡片就在旁边出现。

- **更轻**：只有一个约 4.2 MB 的 exe，不需要安装，也不需要 WebView2；平时只在托盘待命，待命时内存约 0.5 MB。
- **不打扰**：卡片出现在选区旁边，不抢走原窗口焦点，可以接着打字；点卡片外面就收起，需要时用图钉固定。
- **读得更顺**：中文释义在前，英/美发音直接播放；词性标签显示条数，例句按需展开；↑↓、→、Tab、Esc 用键盘就能完成。
- **设置更简单**：自动划词、查词快捷键和浅色/深色都在卡片的设置里；托盘菜单可以查词、开关自动划词和退出。
- **取词更稳**：剪贴板里有复制的文件、Office 和 WPS 复制的内容或矢量图时，浏览器、Windows 设置等位置都能取词，查完剪贴板原样放回；剪贴板实在无法备份时，直接用读到的单词查词，不会碰你的剪贴板。

## 从 0.2.0 升级

1. 在托盘右键旧版图标，选择“退出 WordSide”。
2. 用过安装版的，可以在 Windows“已安装的应用”里卸载 0.2.0。
3. 运行 `WordSide_0.3.0.exe`。自动划词开关、快捷键和浅色/深色设置会沿用。

0.2.0 的主窗口、四套配色和可调大小的浮窗在这一版不再提供。

## 已知限制

- 卡片宽度固定，拖动后的位置暂不记住；多显示器、不同缩放比例下的位置还在完善。
- 开着自动划词时，程序会定时检查选区，CPU 偶尔有极少占用；关闭自动划词时为 0。
- 程序没有数字签名，第一次运行时 Windows 可能提示“已保护你的电脑”，点“更多信息”→“仍要运行”。
- 有的网络访问 Cambridge 会被要求人机验证，这时无法查词，可以换一个网络再试。

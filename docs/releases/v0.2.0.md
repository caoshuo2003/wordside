# WordSide · 词伴 0.2.0

这一版重新设计了界面和图标。

- 四套配色（薄荷绿、雾紫、浅蓝、暖灰）给主窗口和浮窗整体带上浅浅的同色调，浅色、深色各一套。
- 浮窗：中文释义在前；英/美发音合成一行；词性标签显示条数，点一下跳到对应部分；仅有英文释义时有小标签说明；加载时可以取消。
- 主窗口更紧凑：查词框在顶部；快捷键用键帽显示，可修改、撤销或停用；主题和配色一键切换。
- 新的纸白软件图标；托盘图标和窗口图标跟着配色变。
- 程序更小：主程序从约 13.9 MB 减到约 11.9 MB。
- 修复剪贴板里放着从资源管理器复制的文件时，Chrome 网页（如 GitHub）等位置无法自动划词、快捷键提示“当前剪贴板内容暂时无法保留”的问题。

更新前，请先从托盘退出旧版，再安装或运行新版；原有设置会保留。

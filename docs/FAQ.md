# 常见问题

## 取词与快捷键

**关闭自动划词后还能用快捷键吗？**

可以。自动开关只控制选中后的自动弹出，主动快捷键仍可查询。

**已经选中了，为什么读不到？**

不同应用与不同文本区域提供的选区能力不同。重新选中一个单词再按快捷键；确认快捷键已保存、未被其他软件占用。仍失败时，可用手动输入查询。当前版本不能承诺任意 Windows 控件都支持取词。

**会修改原剪贴板吗？**

直接选区读取路径不模拟复制。兼容路径可能读取本次选择产生的剪贴板更新；若原应用启用“选中即复制”，是原应用在选中时写入剪贴板。WordSide 不保证阻止源应用的自动复制行为。

**选区多了标点会怎样？**

会清理首尾符号，保留词内连字符和撇号；不会从完整命令、路径或多行文本里自动截出单词。多选或少选字母则依赖词典建议，不自动替换。

## 网络与速度

**为什么第一次比重复查询慢？**

第一次需要网络连接与完整网页，重复词可能命中内存缓存。连接池会复用，但不能消除 Cambridge 的响应时间，也不保证固定的毫秒级查询。

**怎么使用代理？**

优先在 Windows 中配置系统代理。也可在 PowerShell 中为本次启动设置环境变量，将下面的地址换成自己的 HTTP 代理端口：

```powershell
$env:HTTPS_PROXY = 'http://127.0.0.1:7890'
$env:HTTP_PROXY = 'http://127.0.0.1:7890'
& '.\WordSide_0.1.0.exe'
```

先从托盘退出旧实例，再从该 PowerShell 启动，运行中的旧进程不会自动继承新环境变量。该方法只影响当前 PowerShell 与它启动的进程，不需要修改系统设置；现版本暂无独立代理设置界面。

**显示查询较慢、连接失败或内容不可用怎么办？**

稍后重试，确认网络/代理能打开 [Cambridge Dictionary](https://dictionary.cambridge.org/)。网站暂时不可访问或网页结构变化时，程序会保留错误类别，而非显示“没有这个词”。

## 释义与建议

**为什么没有中文？**

Cambridge 英汉词库可能未收录该词或部分译文。WordSide 保留英英释义与例句，用轻量标记区分，不提供机器翻译来填补。

**为什么拼写建议没有出现？**

只有两种词库都明确缺词且 Cambridge 提供建议时才显示。缩写、随机片段与所有错词不保证有候选；建议请求失败也可能只有缺词提示。

**是不是网页的全部内容？**

不是完整网页复刻。保留原解析器覆盖的词性、音标、音频、核心释义和例句；广告、导航、额外语料栏目等不纳入。获取完整响应并检查结构，是为了避免展示残缺词条。

## 窗口与运行

**固定后还能查新词吗？**

能。自动或快捷键的新词会在固定的同一浮窗更新；窗口位置、大小保持。固定不会暂停自动划词。

**关了设置窗口，为什么程序还在？**

默认关闭后驻留托盘。可在“关闭主窗口时”改为退出；或托盘右键退出。双击托盘直接打开设置。

**便携版需要 Node 吗？**

不需要。运行时是 Tauri / Rust 与 WebView2，Node 只用于开发构建。便携版仍在系统配置目录保存偏好。

**支持 Linux、远程服务器或 tmux 吗？**

当前发布仅 Windows x64 桌面端。其他产品形态需要独立开发，不随本版常驻运行。

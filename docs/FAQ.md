## 安装与运行

**第一次使用应该下载哪个文件？**

推荐 `WordSide_0.1.1_x64-setup.exe`，按提示安装即可。希望解压使用时，选择 `WordSide_0.1.1-portable.zip`，解压全部文件后运行其中的程序。

**为什么默认安装在 AppData\Local，而不是 Program Files？**

安装版默认只为当前 Windows 用户安装，程序位于 `%LOCALAPPDATA%` 下，通常无需管理员权限。`Program Files` 通常用于所有用户安装，两种方式都可正常使用。

**打开时提示缺少 WebView2 怎么办？**

从 [Microsoft 官方页面](https://developer.microsoft.com/en-us/microsoft-edge/webview2/)安装 WebView2 Runtime。联网时可使用 Evergreen Bootstrapper；离线安装时选择 Evergreen Standalone Installer 的 x64 版本。安装后重新打开 WordSide。

**运行后没看到窗口怎么办？**

先检查任务栏的托盘区域，包括折叠的图标，双击 WordSide 图标打开主窗口。如果准备换一个版本，先在托盘右键退出旧实例，再运行新程序。

**便携版如何保存设置？**

快捷键、外观和窗口大小保存在 Windows 应用配置目录。重新打开会沿用设置；把程序复制到另一台电脑时，设置需要重新配置。位置和清理方法见[隐私与本地数据](PRIVACY.md)。

## 取词与快捷键

**关闭自动划词后还能用快捷键吗？**

可以。自动开关控制选中后的自动弹出；选好单词后按快捷键仍可主动查询。

**选中了单词，却没弹出或提示读不到选区？**

先确认“自动划词”已打开，或试着重新选中一个单词后按已保存的快捷键。快捷键也可能被其他软件占用，可以在设置中换一组。

不同应用和文本区域的选区能力不同。有些区域仍无法取词时，可以在 WordSide 中手动输入继续查询。反馈问题时，请说明应用名称、具体区域和使用的快捷键。WordSide 会在设置目录保留最近一次取词故障信息 `capture-status.json`，用于区分失败环节，里面不含选词或剪贴板内容。

**可以在 Windows 终端里用吗？**

WordSide 可以为 Windows 桌面终端中的选词显示释义浮窗，具体效果取决于终端的选区能力和设置。遇到无法取词的区域，可以将单词输入 WordSide 查询。

**选词会影响剪贴板吗？**

WordSide 会临时复制选区来核对实际文字，随后尝试恢复原剪贴板；期间你新复制的内容优先保留。不能完整备份时，会保持当前内容并提示手动输入。临时复制可能被剪贴板历史或第三方工具记录，详细说明见[隐私与数据](PRIVACY.md#选区与剪贴板)。

这项校对依赖源应用支持标准 **Ctrl+Insert** 复制；不支持的区域可以手动输入。自动划词和快捷键采用相同处理方式。

部分应用开启“选中即复制”时，会自行更新剪贴板。这个行为由原应用控制，可以在原应用中关闭。

**选区多了标点会怎样？**

首尾符号会自动清理，例如 `-workspace`、`--workspace` 会查询 `workspace`；单词内部的连字符和撇号会保留。多选或少选了字母时，可以查看词典提供的建议，或重新选取完整单词。

## 网络与速度

**查词需要连接哪里？**

WordSide 直接访问 [Cambridge Dictionary](https://dictionary.cambridge.org/)获取词条和拼写建议，播放发音时获取该网站的音频。查询词的处理方式见[隐私与数据](PRIVACY.md)。

**为什么第一次查询较慢？**

首次查询需要从词典网站读取内容；短时间重复查词时，可以使用内存缓存。网络和代理的连接情况会影响等待时间。

**怎么使用代理？**

可在 Windows 中配置系统代理，再重新启动 WordSide。如果使用本地 HTTP 代理，也可以在 PowerShell 中为本次启动设置环境变量；下面的端口请换成你自己的：

```powershell
$env:HTTPS_PROXY = 'http://127.0.0.1:7890'
$env:HTTP_PROXY = 'http://127.0.0.1:7890'
& '.\WordSide_0.1.1.exe'
```

先在托盘右键退出 WordSide，再进入 EXE 所在目录执行这些命令。它们只影响这个 PowerShell 窗口及从中启动的程序。

**显示查询较慢、连接失败或内容不可用怎么办？**

先在浏览器打开 [Cambridge Dictionary](https://dictionary.cambridge.org/)，确认网络或代理能访问网站，再重新查询。若网站暂时不可用，可稍后再试；如果浏览器访问正常而 WordSide 持续失败，请提交 Issue，附上应用版本和界面提示。

## 释义与建议

**为什么没有中文？**

有些词条或部分释义只有英文内容，会以“英文释义”或“部分仅英文”标记。可以继续阅读英文解释和例句，也可以点击“原词典”查看网页。

**为什么没有拼写建议？**

拼写建议由 Cambridge 提供。两种词库都没找到词条、且词典给出候选时才显示；有时只会出现未找到的提示，这时可以手动修改输入。

**怎样查看词典原页？**

点击浮窗底部的“原词典”，会在默认浏览器打开对应词条。浮窗集中展示释义、例句、词性、音标和发音，原页可继续查看其他内容。

## 窗口与退出

**固定浮窗后还能查新词吗？**

可以。新词会在固定的同一浮窗中更新，窗口位置和大小保持。

**关了主窗口，为什么程序还在？**

默认会隐藏到托盘，双击托盘图标可以重新打开。在“关闭主窗口时”改为“退出 WordSide”，关闭就会结束程序；也可随时在托盘右键退出。

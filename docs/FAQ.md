## 安装与运行

**第一次使用应该下载哪个文件？**

推荐 `WordSide_0.3.0_x64-setup.exe`，按提示安装即可：只装给当前用户，不需要管理员权限，开始菜单里会有 WordSide，还可以选开机自动启动。不想安装的，下载 `WordSide_0.3.0.exe` 放到任意文件夹双击运行；想要附带使用说明和第三方许可的压缩包，选择 `WordSide_0.3.0-portable.zip`。

**怎么开机自动启动？**

用安装版时，在安装完成页勾选“开机时自动启动”。之后想改，重新运行安装包再选一次；卸载时会一并去掉。

**提示“Windows 已保护你的电脑”怎么办？**

WordSide 没有数字签名，Windows 会对不常见的程序提示。点“更多信息”→“仍要运行”即可。

**还需要 WebView2 吗？**

不需要。0.3.0 是原生程序，不依赖 WebView2 或其他运行库。

**运行后没看到窗口怎么办？**

这是正常的：WordSide 只在托盘待命。检查任务栏右下角的托盘区域（包括 ^ 里折叠的图标），左键点 WordSide 图标即可打开卡片。

**0.2.0 还要保留吗？**

不需要，两者同时运行会互相抢快捷键和取词。先在托盘右键退出 0.2.0，再运行 0.3.0 的安装包，它会自动卸载已安装的 0.2.0；用 0.2.0 便携版的，删除旧文件夹即可。设置保存在同一个位置，0.3.0 会沿用自动划词开关、快捷键和浅色/深色。

**设置保存在哪里？**

保存在 Windows 应用配置目录，换文件夹运行程序也会沿用；复制到另一台电脑时需要重新设置。位置和清理方法见[隐私与本地数据](PRIVACY.md)。

## 取词与快捷键

**关闭自动划词后还能用快捷键吗？**

可以。自动划词控制选中后的自动弹出；选好单词后按快捷键仍可主动查询。

**选中了单词，却没弹出卡片？**

先在托盘右键确认“自动划词”已勾选，或试着重新选中一个单词后按快捷键。快捷键被其他软件占用时，托盘会提示，在设置里换一组即可。

不同应用和文本区域的选区能力不同。有些区域仍无法取词时，可以在卡片里手动输入。反馈问题时，请说明应用名称、具体区域和使用的快捷键，并附上设置目录里的 `capture-status.json`：它只记录最近一次取词故障的阶段和状态码，不含选词或剪贴板内容。

**可以在浏览器和 Windows 终端里用吗？**

可以。浏览器的网页和地址栏、Windows 桌面终端里的选词都会显示卡片，具体效果取决于该应用提供的选区能力。遇到无法取词的区域，可以手动输入。

**选词会影响剪贴板吗？**

常见系统文本控件会直接读取选区，不碰剪贴板。浏览器、Word 等需要核对的位置，会先在内存里完整备份当前剪贴板，再临时复制选词核对，随后原样放回；期间你新复制的内容优先保留。从 Office、WPS 复制的嵌入内容和矢量图也能完整备份。

如果当前剪贴板确实无法完整备份，WordSide 不会动它，而是直接使用从该应用读到的单词查词。临时复制可能被剪贴板历史或第三方工具记录，详细说明见[隐私与数据](PRIVACY.md#选区与剪贴板)。

部分应用开启“选中即复制”时，会自行更新剪贴板。这个行为由原应用控制，可以在原应用中关闭。

**选区多了标点会怎样？**

首尾符号会自动清理，例如 `-workspace`、`--workspace` 会查询 `workspace`；单词内部的连字符和撇号会保留。多选或少选了字母时，可以查看词典提供的建议，或重新选取完整单词。

## 网络与速度

**查词需要连接哪里？**

WordSide 直接访问 [Cambridge Dictionary](https://dictionary.cambridge.org/)获取词条和拼写建议，播放发音时获取该网站的音频。查询词的处理方式见[隐私与数据](PRIVACY.md)。

**为什么第一次查询较慢？**

首次查询需要从词典网站读取内容；15 分钟内重复查同一个词会直接使用内存缓存。网络和代理的连接情况会影响等待时间。

**怎么使用代理？**

可在 Windows 中配置系统代理，再重新启动 WordSide。如果使用本地 HTTP 代理，也可以在 PowerShell 中为本次启动设置环境变量；下面的端口请换成你自己的：

```powershell
$env:HTTPS_PROXY = 'http://127.0.0.1:7890'
$env:HTTP_PROXY = 'http://127.0.0.1:7890'
& '.\WordSide_0.3.0.exe'
```

先在托盘右键退出 WordSide，再进入 EXE 所在目录执行这些命令。它们只影响这个 PowerShell 窗口及从中启动的程序。

**提示连接失败、需要人机验证或内容不可用怎么办？**

先在浏览器打开 [Cambridge Dictionary](https://dictionary.cambridge.org/)，确认网络或代理能访问网站。有的网络会被网站要求人机验证，这时 WordSide 无法代为完成，可以换一个网络或稍后再试。若浏览器访问正常而 WordSide 持续失败，请提交 Issue，附上应用版本和卡片上的提示。

## 释义与建议

**为什么没有中文？**

有些词条或部分释义只有英文内容，会标记“仅英文”。可以继续阅读英文解释和例句，也可以点击“原词典”查看网页。

**词性标签里的“其他”是什么？**

Cambridge 没有标注词性的释义，例如 `com` 里“company 的缩写”那一条。

**为什么没有拼写建议？**

拼写建议由 Cambridge 提供。两种词库都没找到词条、且词典给出候选时才显示；有时只会出现未找到的提示，这时可以手动修改输入。

**怎样查看词典原页？**

点击卡片底部的“原词典”，或在释义上右键选择“在 Cambridge 打开”，会在默认浏览器打开对应词条。

## 卡片与退出

**固定卡片后还能查新词吗？**

可以。新词会在固定的同一张卡片中更新。

**卡片能调大小、记住位置吗？**

这一版卡片宽度固定，高度随内容变化；拖动后的位置暂时不会记住。这两项在后续版本中计划改进。

**怎么退出？**

在托盘右键 WordSide，选择“退出”。

**文字看起来发虚或发粗？**

卡片的文字按屏幕的像素密度调整：1080p 等 100%、125% 缩放的屏幕上，笔画对齐像素；2K、4K 等高缩放屏幕上更平滑。如果仍觉得不清楚，请截图提交 Issue，并说明屏幕分辨率和 Windows 的缩放比例。

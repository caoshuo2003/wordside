# WordSide · 词伴桌面端

当前 **0.1.0 正式版**，Windows x64。TypeScript 提供设置与释义浮窗，Tauri / Rust 在桌面程序内访问 Cambridge。

- 自动划词、可配置快捷键和手动输入。
- 符号清理、完整词条与候选、简短用户提示。
- 四套日夜配色，浮窗拖动、缩放、固定与尺寸记忆。
- 主窗口关闭可选托盘或退出，双击托盘直接打开。
